
# Retrieve
Read README, the knowledge index when present, and only the relevant subjects or the handover that
matches the task. Search index cues, then likely branches. Broaden only when that pass does not
answer the question.

Include a source-subject link in a factual answer. When the answer or the next step depends on
current state, apply the freshness rules in the global agent rules. On access failure, state what
remains unverified.

An investigation uses the same reads, then separates supported findings, proposals, and unresolved
questions. When knowledge changes are authorized, save a new reusable finding through distill.md.
Scratch may use `work/` under the knowledge.md lifecycle. Capture unfinished work when continuation
remains. A question stays read-only unless the request authorizes a change. Discussion alone does
not create an outputs file.
