# Retention

## Defaults

For disposable inputs and generated intermediates: delete after processing, once you verify:

- Useful content and necessary evidence were preserved
- Relevant outputs were checked
- References were repaired

Explicit keep requests override deletion.
Keep unprocessed or uncertain material until resolved.
Keep durable outputs and maintained components.
Never apply input cleanup to external originals, repositories, or user-authored work outside the
processed set.
A filing-only request is not completed extraction.

## Filing kept originals

- Move processed retained originals to `sources/` and update references
- Keep means one copy, not intake plus `sources/`
- Verify the moved content before removing a duplicate
- Explain the source role where referenced
- Filename collisions: compare contents; keep distinct sources under distinct names; never
  overwrite evidence
- Remove superseded working copies and resolved checkpoint detail after preservation checks
- No archives or dated snapshots by default
- Check file count and bytes (including history/caches when present); archiving is not shrinking
- Never hit a size target by dropping unique useful knowledge
