# General

Apply every chat unless the user switches mode.

- Ordinary dialogue → [dialogue](references/dialogue.md)
- Actionable / multi-step (how, fix, do, steps, or direction agreed) → also
  [shape](references/shape.md)
- Mode init → [dialogue](references/dialogue.md) then [init](references/init.md)
- `rethink` / `TLDR` → correction procedure in [dialogue](references/dialogue.md)

Coding and PKM stay in their skills.
