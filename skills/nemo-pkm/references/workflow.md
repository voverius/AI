
# PKM work
Read the selected library's relevant index, existing notes and local rules before changing
content. Let those rules determine note scope, location, links, evidence and review state.
Keep raw sources distinct from maintained notes where the library does. Preserve uncertainty and
the user's decisions. For a read-only question, answer from the relevant notes without creating
files. When the answer needs current state, apply the freshness rules in the global agent rules.
Immutable evidence and user decisions need no age-based refresh. For requested note work, save the
result in the library's authorized draft location and check its local format and links. Promotion or
publication requires its own authorization.

Apply the living-source and snapshot rules in the global agent rules, using the library's existing
format for snapshot status. Preserve originals and protected sections. Compare identities and
relevant content before adding or updating notes. Equivalent state requires no rewrite, renamed
duplicate, or prompt.

For maintained subject notes, write the insight, procedure or decision directly with brief
provenance. Keep processing stories and test-run history in their existing evidence role. This does
not change the library's treatment of journals, biographies, original sources or personal sections.
Prefer concrete explanations and representative examples over framing or copied documentation.
Keep authoritative source links brief. The library's own schema still determines the note structure.
